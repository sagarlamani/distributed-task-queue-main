================================================================================
                            DATA FLOW
================================================================================

1. TASK SUBMISSION
   Client → FastAPI API → Redis Queue (Priority-based)

2. TASK PROCESSING
   Redis Queue → Worker Node → Task Handler → Execution

3. STATUS UPDATE
   Worker → PostgreSQL (Metadata) → Redis Cache (Results)

4. MONITORING
   All Components → Prometheus → Grafana Dashboard

5. FAILURE HANDLING
   Failed Task → Retry Queue → Dead Letter Queue (after max retries)
